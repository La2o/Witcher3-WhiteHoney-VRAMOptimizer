White Honey - VRAM Optimizer (The Witcher 3)
============================================

Double-click the numbered files in order:

  1 - Scan my mods.bat
      Checks every texture and mesh mod you have installed (mods and dlc
      folders) and opens a report in your browser. The heaviest mods are at
      the top. Changes nothing.
      Using Mod Organizer 2? If no mods are found it asks for your MO2 folder
      once. Run through MO2, step 2 saves the fix as an MO2 mod named
      "White Honey Budget Fix": press F5 in MO2 and tick it to enable it.

  2 - Apply budget fix.bat   (optional)
      If the report says you are over budget, this adds ONE extra mod folder
      with half-size copies of only the heaviest textures. Your mods are not
      changed. It scans first, then shows how many textures it would shrink,
      how big the fix will be and roughly how long it takes, and asks before
      writing. A second question covers 4K textures of new armor, weapons and
      other added content (they only use VRAM while worn or spawned): shrink
      them to 2K, and if you like, further to 1K (softer up close, hard to
      see on small screens like the Steam Deck's). When it is done it shows
      the new folder in Explorer.
      Before that it lists the mods the fix would touch (with textures and
      VRAM for each). Type the numbers of mods to leave untouched, like 1,3,
      or press Enter to trim them all. It then asks whether to remember
      your choice. If a fix is already applied and you exclude a mod later,
      the next scan says the fix is out of date: run step 2 again.

  3 - Measure VRAM in game.bat   (optional)
      Records how much video memory the game really uses while you play.
      Run it once named "before", apply the fix, then again named "after"
      in the same save to see the difference.

  Undo budget fix.bat
      Removes the extra folder from step 2, wherever it was saved (also the
      MO2 mod "White Honey Budget Fix"). Everything is back as it was.

This folder can live anywhere (game folder, Desktop, ...). If the tool can't
find your game, it asks for the game folder once and remembers it.
A shortcut says WhiteHoney.exe is missing? Your antivirus probably removed
it: restore it in Windows Security > Virus & threat protection > Protection
history, or download the mod again.
Reports are saved next to these files (White-Honey-Report.html).
Mods to keep out of the fix are listed in White Honey - Excluded mods.txt
(next to these files; the first scan creates it). Open it in Notepad.
Advanced options: open a terminal here and run  WhiteHoney.exe --help
